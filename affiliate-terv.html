2. 🏥 Biztosítás — a legnagyobb pénz

2.1 Miért ez a #1 prioritás?

A Kinti user a Szolgáltató-váltó és a Bérkalkulátor modulban ÉPPEN MOST dönt biztosításról. Ez a legértékesebb pillanat: a biztosítók €200–400/szerződés jutalékot fizetnek a közvetítőnek. A Kinti nem közvetít — a usert átirányítja egy engedéllyel rendelkező összehasonlító partnerre (Comparis, Check24) affiliate linken.

  • Ország-aware kártya (a user preferált országához igazodik)

4. 🚚 Költöztetés — lead generation

4.1 Hogyan működik

A user a Költözés checklist-ben vagy az Ügyintézés-varázslóban éppen most szervezi a költözését. Beír egy „Költöztetés ajánlatkérés" formot (honnan → hová, m³, dátum). A Kinti a kvalifikált leadet 3 partner költöztető cégnek továbbítja. A user 24h-n belül 3 ajánlatot kap.

9.3 A biztosítás-csatorna dominanciája

A teljes affiliate bevétel 60–70%-a a biztosítás-csatornából jön.
